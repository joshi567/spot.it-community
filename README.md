# SpotIt — Community Issues

**See it. Spot it. Fix it.**

SpotIt is a community-focused website that helps people highlight local civic issues, support existing reports, and bring attention to problems that need action.

## Features
- 📸 Report civic issues
- 🤝 Add support to existing issues
- 🔍 Search and filter reports
- 🎨 Simple, colorful interface
